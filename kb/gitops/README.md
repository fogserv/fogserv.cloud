# GitOps Practice Folder

This directory captures operational playbooks that make GitOps the single source of truth for fogserv.cloud.

## Contents
- `gitops.md` — Workflow steps, tooling, and documentation hygiene for branches, tickets, and Forgejo Actions.

## Update Rules
- Every addition must include a ticket reference and state whether Forgejo Actions or Gatekeeper policies enforce it.  
- Track drifts/resolutions in `Next Steps` or `Change Log` so future agents can replay what changed.
