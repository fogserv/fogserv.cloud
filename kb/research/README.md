# Research Logs

This folder captures the external sources we mined for the KB. Each entry outlines what we learned, why it mattered, and which related topics emerged from the same thread.

## Update Rules
- Use the KB layout and include `Sources & Related` so future agents can trace references.  
- When a new topic keeps appearing in searches (e.g., MCP, semantic telemetry, DevSecOps guardrails), create a subentry or expand an existing one to capture that nuance.
